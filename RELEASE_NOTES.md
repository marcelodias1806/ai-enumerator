# AI Enumerator v1.0.1 Community

First public community-source release of AI Enumerator.

## Highlights

- curated GenAI intelligence catalog
- live DNS / TCP / TLS / HTTP egress validation
- exposure views by vendor and category
- AI API and model-distribution visibility
- historical scan comparison and change detection
- multi-probe assessment model
- AI Egress Exposure Score
- executive PDF and technical CSV export
- policy simulation and text feeds
- local RBAC authentication
- Docker Compose deployment

## Scope

This release focuses on GenAI egress exposure intelligence. It does not authenticate to third-party AI services, invoke inference, send prompts or download models.
